# Phase 1b-2: Shopify Connection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an owner or admin connect a Shopify store (OAuth), keep the token encrypted, receive and store Shopify webhooks, and handle uninstall plus the three mandatory privacy webhooks, all built and verified against a fake Shopify.

**Architecture:** Pure Shopify logic (domain validation, HMAC, token exchange, webhook registration) lives in `packages/connectors/src/shopify` behind an injected `HttpClient`. Two new tenant tables (`oauth_states`, `webhook_events`) plus four narrow SECURITY DEFINER functions cover the pre-org lookups and the purge. The NestJS API owns routes and persistence; the worker processes stored webhook events. The 1b-1 follow-up chores run first.

**Tech Stack:** TypeScript strict, NestJS 11, Drizzle 0.45, Postgres RLS, BullMQ/ioredis (already in the stack), zod v3, Vitest 5, Next.js 15 (App Router).

**Spec:** `docs/superpowers/specs/2026-10-06-phase1b2-shopify-connection-design.md` (the spec is the authority; where this plan refines it the Global Constraints say so).

## Global Constraints

- Branch `phase1b2-shopify` (already created, spec committed). Every commit message ends with the exact line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Money is integer cents, percentages integer basis points (not touched here, but never introduce floats).
- Every tenant table: `app_secure_tenant_table` in a custom migration, a fixture in `packages/db/test/fixtures.ts`, composite `(org_id, id)` foreign keys. The isolation suite must pass.
- Migrations are generated by `drizzle-kit generate` (never hand-edit generated SQL); RLS and functions go in `drizzle-kit generate --custom` migrations. Next free number is 0013. If drizzle-kit orders statements badly (as in 1b-1), split into several migrations and report it.
- Every new SECURITY DEFINER function sets `search_path = pg_catalog, public, pg_temp`, `REVOKE ALL ... FROM PUBLIC`, revokes EXECUTE from `anon` and `authenticated` when those roles exist, and is granted only to `app_user`. None may ever be wired to an API route except the two public flows named in the spec (`app_consume_oauth_state` from the callback, `app_find_store_connection` from the webhook receiver and callback).
- Tokens, secrets, state nonces and webhook payloads are never logged, never put in URLs (except the nonce as OAuth `state`), job data, `last_error`, audit metadata or error messages. All stored error text passes through `sanitizeMessage`.
- All HMAC comparisons are constant-time (`crypto.timingSafeEqual` on equal-length buffers; unequal length returns false).
- Credentials are encrypted with AAD `connection:<id>` via `encryptConnectionCredentials`. Job data carries only ids.
- The shop domain is validated with `isValidShopDomain` before any URL is built or request made. HTTP clients never follow redirects.
- Shopify behaviour (API version, GraphQL names, endpoint shapes) must be confirmed against Shopify's current official docs when implementing; put the doc link in a code comment. The code in this plan reflects the documented contracts as of writing; if the docs differ, follow the docs and report the difference.
- TypeScript strict, no `any` without a comment. Prettier formatting is applied before every commit (`pnpm exec prettier --write <changed files>`).
- After any test run that starts a database, check for leftover `postgres` processes and `%TEMP%\erq-pg-*` directories (Task 1 should make this unnecessary; until it is done, clean up by hand: `Get-Process postgres | Stop-Process -Force`).
- Redis/BullMQ-dependent tests are skipped without Docker (`dockerAvailable()`) and are reported as unverified.

## Review Focus

Failure modes the spec implies that deserve explicit tests (each is pinned in the task named):
1. A look-alike shop host (`evil.com/.myshopify.com`, `a.myshopify.com.evil.com`, uppercase, ports, userinfo, unicode) must never validate — Task 6.
2. An OAuth callback replayed, expired, or presented with a state minted for another shop must fail and consume nothing twice — Tasks 9, 12.
3. A webhook with a tampered body, a signature for another secret, a missing or non-base64 header must be rejected without storing anything — Tasks 7, 13.
4. The same webhook delivered twice must be stored once and processed once — Tasks 13, 14.
5. `shop/redact` must remove one connection's data (ledger included) and nothing of another connection or tenant — Task 10.
6. A viewer or analyst must not be able to install or disconnect, and the connections list must never contain credentials — Task 11.

import { execFile, execFileSync } from 'node:child_process';
import { readFileSync, rmSync } from 'node:fs';
// ...existing imports (mkdtemp, rm from node:fs/promises stay)

const live = new Set<string>(); // data directories of embedded servers that are still running

/** Kills the postmaster (and its backends) found in dir/postmaster.pid, then removes dir. Never throws. */
function killServerSync(dir: string): void {
  try {
    const pid = Number(readFileSync(path.join(dir, 'postmaster.pid'), 'utf8').split('\n')[0]);
    if (Number.isSafeInteger(pid) && pid > 0) {
      if (process.platform === 'win32') {
        // /T kills the whole tree: pg.stop() only stops the postmaster and leaves backends behind on Windows.
        execFileSync('taskkill', ['/PID', String(pid), '/T', '/F'], { stdio: 'ignore', windowsHide: true });
      } else {
        process.kill(pid, 'SIGQUIT'); // immediate shutdown; the directory is deleted next
      }
    }
  } catch {
    // already gone
  }
  try {
    rmSync(dir, { recursive: true, force: true, maxRetries: 20, retryDelay: 250 });
  } catch {
    // best effort
  }
  live.delete(dir);
}

/** Reaps every embedded database this process started and did not stop. Safe to call repeatedly. */
export function cleanupLeakedDatabases(): void {
  for (const dir of [...live]) killServerSync(dir);
}

let hooked = false;
function installHooks(): void {
  if (hooked) return;
  hooked = true;
  process.on('exit', cleanupLeakedDatabases);
  for (const signal of ['SIGINT', 'SIGTERM'] as const) {
    process.on(signal, () => {
      cleanupLeakedDatabases();
      process.exit(1);
    });
  }
}
```

// packages/connectors/src/sanitize.ts
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

/**
 * Makes error text safe to store or return: strips tokens, secrets and query strings, caps the length.
 * Connector errors may embed URLs or response fragments, so everything stored in last_error or event errors goes through here.
 */
export function sanitizeMessage(input: unknown, max = 500): string {
  let text: string;
  try {
    text = input instanceof Error ? input.message : String(input);
  } catch {
    text = 'unprintable error';
  }
  text = text
    .replace(/\bshp(?:at|ca|ss|pa)_[A-Za-z0-9]+/g, '[redacted]')
    .replace(/\bBearer\s+[A-Za-z0-9._~+/=-]+/gi, 'Bearer [redacted]')
    .replace(
      /\b(access_token|client_secret|api_secret|secret|token|password|hmac|code)\s*[=:]\s*[^\s&,;]+/gi,
      '$1=[redacted]',
    )
    .replace(/\?[^\s#]*(#\S*)?/g, '?[redacted]')
    .replace(/[A-Za-z0-9_+/=-]{32,}/g, (m) => (UUID.test(m) ? m : '[redacted]'));
  return text.slice(0, max);
}
```

import { TransientError } from '../errors';

export interface HttpRequest { method: 'GET' | 'POST'; url: string; headers?: Record<string, string>; body?: string }
export interface HttpResponse { status: number; headers: Record<string, string>; body: string }
export interface HttpClient { request(req: HttpRequest): Promise<HttpResponse> }

export function createFetchHttpClient(opts: { timeoutMs?: number; fetchImpl?: typeof fetch } = {}): HttpClient {
  const doFetch = opts.fetchImpl ?? fetch;
  return {
    async request(req) {
      try {
        const res = await doFetch(req.url, {
          method: req.method,
          headers: req.headers,
          body: req.body,
          redirect: 'error', // the host was validated, a redirect target would not be
          signal: AbortSignal.timeout(opts.timeoutMs ?? 10_000),
        });
        const headers: Record<string, string> = {};
        res.headers.forEach((v, k) => (headers[k.toLowerCase()] = v));
        return { status: res.status, headers, body: await res.text() };
      } catch {
        // Deliberately drop the cause: it can contain the URL and its query string.
        throw new TransientError('network error');
      }
    },
  };
}

```ts
// packages/connectors/src/shopify/hmac.ts
// OAuth query hmac (hex): https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/authorization-code-grant
// Webhook X-Shopify-Hmac-Sha256 (base64 over the raw body): https://shopify.dev/docs/apps/build/webhooks/subscribe/https
import { createHmac, timingSafeEqual } from 'node:crypto';
import { isValidShopDomain } from './domain';

function safeEqual(a: Buffer, b: Buffer): boolean {
  return a.length === b.length && timingSafeEqual(a, b);
}

export function verifyOAuthQuery(
  query: Record<string, string | string[] | undefined>,
  apiSecret: string,
  opts: { now?: Date; maxAgeSeconds?: number } = {},
): boolean {
  const { hmac, ...rest } = query;
  if (typeof hmac !== 'string' || !/^[0-9a-f]{64}$/i.test(hmac)) return false;
  const pairs: string[] = [];
  for (const key of Object.keys(rest).sort()) {
    const value = rest[key];
    if (typeof value !== 'string') return false; // repeated parameters are never valid
    pairs.push(`${key}=${value}`);
  }
  const expected = createHmac('sha256', apiSecret).update(pairs.join('&')).digest();
  if (!safeEqual(expected, Buffer.from(hmac, 'hex'))) return false;
  const ts = Number(rest.timestamp);
  if (!Number.isSafeInteger(ts)) return false;
  const nowSec = Math.floor((opts.now ?? new Date()).getTime() / 1000);
  return ts <= nowSec + 60 && nowSec - ts <= (opts.maxAgeSeconds ?? 600);
}

export function verifyWebhookSignature(
  rawBody: Buffer | string,
  hmacHeader: string | undefined,
  apiSecret: string,
): boolean {
  if (!hmacHeader || !/^[A-Za-z0-9+/]+={0,2}$/.test(hmacHeader)) return false;
  const expected = createHmac('sha256', apiSecret).update(rawBody).digest();
  return safeEqual(expected, Buffer.from(hmacHeader, 'base64'));
}

export interface WebhookHeaders {
  topic: string;
  shop: string;
  webhookId: string;
  eventId: string | null;
}

export function parseWebhookHeaders(
  headers: Record<string, string | string[] | undefined>,
): WebhookHeaders | null {
  const lower: Record<string, string> = {};
  for (const [k, v] of Object.entries(headers)) {
    const value = Array.isArray(v) ? v[0] : v;
    if (typeof value === 'string') lower[k.toLowerCase()] = value;
  }
  const topic = lower['x-shopify-topic'];
  const shop = lower['x-shopify-shop-domain'];
  const webhookId = lower['x-shopify-webhook-id'];
  if (!topic || !webhookId || !shop || !isValidShopDomain(shop)) return null;
  return { topic, shop, webhookId, eventId: lower['x-shopify-event-id'] || null };
}

// packages/connectors/src/shopify/token.ts
// https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/authorization-code-grant
import { z } from 'zod';
import { AuthError, PermanentError, RateLimitedError, TransientError } from '../errors';
import { isValidShopDomain } from './domain';
import type { HttpClient } from './http';

const tokenBody = z.object({ access_token: z.string().min(1), scope: z.string().default('') });

export async function exchangeCodeForToken(
  http: HttpClient,
  p: { shop: string; apiKey: string; apiSecret: string; code: string },
): Promise<{ accessToken: string; scopes: string[] }> {
  if (!isValidShopDomain(p.shop)) throw new PermanentError('Invalid shop domain');
  const res = await http.request({
    method: 'POST',
    url: `https://${p.shop}/admin/oauth/access_token`,
    headers: { 'content-type': 'application/json', accept: 'application/json' },
    body: JSON.stringify({ client_id: p.apiKey, client_secret: p.apiSecret, code: p.code }),
  });
  if (res.status === 401 || res.status === 403) throw new AuthError('Shopify rejected the app credentials');
  if (res.status === 429) {
    const seconds = Number(res.headers['retry-after']);
    throw new RateLimitedError(Number.isFinite(seconds) && seconds >= 0 ? seconds * 1000 : 2000);
  }
  if (res.status >= 500) throw new TransientError('Shopify is temporarily unavailable');
  if (res.status !== 200) throw new PermanentError('Shopify rejected the authorization code');
  let parsed: z.infer<typeof tokenBody>;
  try {
    parsed = tokenBody.parse(JSON.parse(res.body));
  } catch {
    throw new PermanentError('Shopify returned an unreadable token response');
  }
  return {
    accessToken: parsed.access_token,
    scopes: parsed.scope.split(',').map((s) => s.trim()).filter(Boolean),
  };
}

// packages/connectors/src/shopify/webhooks.ts
// https://shopify.dev/docs/api/admin-graphql/latest/mutations/webhookSubscriptionCreate
// The privacy topics (customers/data_request, customers/redact, shop/redact) are configured with the app, not per shop.
import { AuthError, TransientError } from '../errors';
import { isValidShopDomain } from './domain';
import type { HttpClient } from './http';

export const SHOPIFY_DATA_WEBHOOK_TOPICS = [
  'app/uninstalled',
  'orders/create',
  'orders/updated',
  'orders/cancelled',
  'refunds/create',
  'products/create',
  'products/update',
  'products/delete',
  'inventory_levels/update',
] as const;

const MUTATION = `mutation Subscribe($topic: WebhookSubscriptionTopic!, $url: URL!) {
  webhookSubscriptionCreate(topic: $topic, webhookSubscription: { callbackUrl: $url, format: JSON }) {
    userErrors { field message }
  }
}`;

/** `orders/create` becomes `ORDERS_CREATE`, `inventory_levels/update` becomes `INVENTORY_LEVELS_UPDATE`. */
export const topicToEnum = (topic: string): string => topic.replace(/\//g, '_').toUpperCase();

export async function registerWebhooks(
  http: HttpClient,
  p: { shop: string; accessToken: string; callbackUrl: string; apiVersion: string; topics?: readonly string[] },
): Promise<{ registered: string[]; failed: string[] }> {
  if (!isValidShopDomain(p.shop)) throw new RangeError('invalid shop domain');
  const registered: string[] = [];
  const failed: string[] = [];
  for (const topic of p.topics ?? SHOPIFY_DATA_WEBHOOK_TOPICS) {
    const res = await http.request({
      method: 'POST',
      url: `https://${p.shop}/admin/api/${p.apiVersion}/graphql.json`,
      headers: { 'content-type': 'application/json', 'X-Shopify-Access-Token': p.accessToken },
      body: JSON.stringify({ query: MUTATION, variables: { topic: topicToEnum(topic), url: p.callbackUrl } }),
    });
    if (res.status === 401 || res.status === 403) throw new AuthError('Shopify rejected the access token');
    if (res.status >= 500) throw new TransientError('Shopify is temporarily unavailable');
    if (res.status !== 200) {
      failed.push(topic);
      continue;
    }
    try {
      const json = JSON.parse(res.body) as {
        errors?: unknown;
        data?: { webhookSubscriptionCreate?: { userErrors?: { message?: string }[] } };
      };
      const result = json.data?.webhookSubscriptionCreate;
      const onlyDuplicates = (result?.userErrors ?? []).every((e) => /already been taken/i.test(e.message ?? ''));
      if (!json.errors && result && onlyDuplicates) registered.push(topic);
      else failed.push(topic);
    } catch {
      failed.push(topic);
    }
  }
  return { registered, failed };
}

// packages/connectors/src/testing/fake-shopify.ts
import type { HttpClient, HttpRequest, HttpResponse } from '../shopify/http';
import { SHOPIFY_DATA_WEBHOOK_TOPICS, topicToEnum } from '../shopify/webhooks';

const ENUM_TO_TOPIC = new Map<string, string>(SHOPIFY_DATA_WEBHOOK_TOPICS.map((t) => [topicToEnum(t), t]));

/** In-memory Shopify for tests: OAuth token exchange and webhook subscriptions. Records every request. */
export class FakeShopify implements HttpClient {
  readonly requests: HttpRequest[] = [];
  readonly subscriptions = new Map<string, string>();
  private readonly scripted: HttpResponse[] = [];
  private readonly token: string;
  private readonly scope: string;
  private readonly codes: Set<string>;

  constructor(opts: { token?: string; scope?: string; codes?: Set<string> } = {}) {
    this.token = opts.token ?? 'shpat_fake_token';
    this.scope = opts.scope ?? 'read_orders,read_products';
    this.codes = opts.codes ?? new Set(['good-code']);
  }

  /** The next request answers with this status and an empty JSON body. */
  failNext(status: number, headers: Record<string, string> = {}): void {
    this.scripted.push({ status, headers, body: '{}' });
  }
  /** The next request answers with exactly this response. */
  respondNext(res: { status: number; body: string; headers?: Record<string, string> }): void {
    this.scripted.push({ status: res.status, headers: res.headers ?? {}, body: res.body });
  }

  async request(req: HttpRequest): Promise<HttpResponse> {
    this.requests.push(req);
    const scripted = this.scripted.shift();
    if (scripted) return scripted;
    const url = new URL(req.url);
    if (url.pathname === '/admin/oauth/access_token') {
      const body = JSON.parse(req.body ?? '{}') as { code?: string };
      if (!body.code || !this.codes.has(body.code)) {
        return { status: 400, headers: {}, body: '{"error":"invalid_request"}' };
      }
      return { status: 200, headers: {}, body: JSON.stringify({ access_token: this.token, scope: this.scope }) };
    }
    if (/^\/admin\/api\/[^/]+\/graphql\.json$/.test(url.pathname)) {
      const { variables } = JSON.parse(req.body ?? '{}') as { variables: { topic: string; url: string } };
      const topic = ENUM_TO_TOPIC.get(variables.topic) ?? variables.topic;
      const exists = this.subscriptions.has(topic);
      if (!exists) this.subscriptions.set(topic, variables.url);
      const userErrors = exists ? [{ field: ['topic'], message: 'Address for this topic has already been taken' }] : [];
      return { status: 200, headers: {}, body: JSON.stringify({ data: { webhookSubscriptionCreate: { userErrors } } }) };
    }
    return { status: 404, headers: {}, body: '{}' };
  }
}

RETURNS void
LANGUAGE plpgsql SECURITY DEFINER SET search_path = pg_catalog, public, pg_temp AS $$
DECLARE v_shop text;
BEGIN

   WHERE org_id = p_org_id AND id = p_connection_id;
  IF NOT FOUND THEN
    RETURN;
  END IF;

export interface WebhookQueue {

}

/** Deterministic job id: the same event is never queued twice while its job is retained. BullMQ ids may not contain ':'. */
export class BullMqWebhookQueue implements WebhookQueue {
  constructor(private readonly queue: Queue) {}
  async enqueue(job: WebhookJob): Promise<void> {
    await this.queue.add('webhook', job, {
      jobId: `${job.orgId}_${job.eventId}`,
      attempts: 5,
      backoff: { type: 'exponential', delay: 5_000 },
      removeOnComplete: { count: 1_000 },
      removeOnFail: { count: 5_000 },
    });
  }
}

@Injectable()
export class ConnectionsService {
  constructor(
    @Inject(TENANT_DB) private readonly db: TenantDb,
    @Inject(SHOPIFY_CONFIG) private readonly config: ShopifyConfig | null,
  ) {}

  private requireConfig(): ShopifyConfig {
    if (!this.config) throw new ApiError(503, 'shopify_not_configured', 'Shopify is not configured on this server');
    return this.config;
  }

  async startInstall(orgId: string, userId: string, input: string): Promise<InstallResponse> {
    const cfg = this.requireConfig();
    const shop = normalizeShopInput(input);
    if (!isValidShopDomain(shop)) {
      throw new ApiError(400, 'invalid_shop', 'Enter your store address like my-store.myshopify.com');
    }
    const nonce = generateOAuthNonce();
    await this.db.withTenant(orgId, async (tx) => {
      await tx.delete(oauthStates).where(lt(oauthStates.expiresAt, new Date())); // lazy cleanup, no scheduler needed
      await tx.insert(oauthStates).values({
        orgId, userId, platform: 'shopify', shop,
        nonceHash: hashOAuthNonce(nonce),
        expiresAt: new Date(Date.now() + 10 * 60_000),
      });
    });
    return { authorizeUrl: buildAuthorizeUrl({ shop, apiKey: cfg.apiKey, scopes: cfg.scopes, redirectUri: cfg.redirectUri, state: nonce }) };
  }

  list(orgId: string): Promise<ConnectionDto[]> {
    return this.db.withTenant(orgId, async (tx) => {
      const rows = await tx.select().from(storeConnections).orderBy(storeConnections.createdAt);
      return rows.map((r) => ({
        id: r.id, platform: r.platform, shop: r.externalAccountId, status: r.status,
        lastSyncedAt: r.lastSyncedAt?.toISOString() ?? null, lastError: r.lastError,
      }));
    });
  }

  async disconnect(orgId: string, userId: string, id: string): Promise<void> {
    await this.db.withTenant(orgId, async (tx) => {
      const rows = await tx
        .update(storeConnections)
        .set({ status: 'disconnected', encryptedCredentials: null })
        .where(and(eq(storeConnections.orgId, orgId), eq(storeConnections.id, id)))
        .returning({ id: storeConnections.id });
      if (rows.length === 0) throw new ApiError(404, 'connection_not_found', 'Connection not found');
      await insertAudit(tx, { orgId, actorUserId: userId, action: 'connection.disconnected', entityType: 'store_connection', entityId: id });
    });
  }
}

The stored payload is the parsed JSON body; a non-JSON body is `401`-free but answered `400 invalid_payload` after signature verification. Events for `disconnected` connections are stored too (the privacy topics arrive after uninstall). Status codes: 200 for stored, duplicate and unknown shop; 401 only for signature problems.

- Produces:
  - `processWebhookEvent(deps: { db: TenantDb; connections: ConnectionsApi; now?: () => Date }, job: WebhookJob): Promise<'processed' | 'deferred' | 'ignored' | 'skipped'>`
  - `sweepStaleWebhookEvents(deps: { connections: ConnectionsApi; enqueuer: WebhookEnqueuer; now?: () => Date }, opts?: { olderThanMs?: number; limit?: number }): Promise<number>` (default 10 minutes, limit 200; returns how many were enqueued)

- Behaviour of `processWebhookEvent`:
  1. Claim: under `withTenant(job.orgId)` set the event `processing` only if it is `received` or `failed`, or `processing` with `updated_at` older than 15 minutes (a crashed worker); no row means `'skipped'` (already handled, in flight elsewhere, or purged).
  2. Dispatch by topic: `app/uninstalled` → connection `disconnected`, `encrypted_credentials = null`, audit `connection.uninstalled` (no actor), event `processed`; `customers/data_request` and `customers/redact` → audit `privacy.request_recorded` (entity `webhook_event`, metadata `{ topic }` only, no payload), event `processed` (we hold no customer PII; see the spec); `shop/redact` → `connections.purgeStoreConnection(orgId, storeConnectionId)` (the event row is removed by the cascade, return `'processed'`); the eight data topics (`orders/create`, `orders/updated`, `orders/cancelled`, `refunds/create`, `products/create`, `products/update`, `products/delete`, `inventory_levels/update`) → status `deferred`; anything else → `ignored`.
  3. Failure: mark the event `failed` with `sanitizeMessage(error)` (best effort; a failure to record the failure must not mask the original error) and rethrow so BullMQ retries.
